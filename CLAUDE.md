# noletorious-ui

Shared UI design system and reusable component library for the `single-purpose` ecosystem.

## Goals & Principles

- **Cohesive Design Tokens**: Shared typography, elevation, motion, border-radius, and calibrated dark/light palettes.
- **High-Contrast Themes**: Purposefully crafted light and dark themes that avoid muddy gray-on-gray or low-contrast text.
- **Plug-and-Play**: Built to be consumed by `single-purpose` apps (`apps/secure-voice`, etc.) and future single-purpose builds.
- **Skills Integrated**: Guided by `ui-ux-pro-max-skill`, `design-system`, and `ui-styling`.

## Rules & Working Agreement

- No `git push` unless requested.
- Always verify builds with `npm run build` or `type-check`.
- Export modular UI components (Navbars, Modals, Audio Visualizers, Badges, Cards, Brand Logos).

## Tokens

Today the system has color tokens only. Spacing, radius and type use Tailwind defaults.

### Where they live

- `tokens/core.json`: raw palette, DTCG format. Names are `{family}.{lightness}` from the HSL value: `gray.100`, `red.51`, `blue.50`, `blue.53`, `blue.60`, `paper.98`, `slate.4` to `slate.98`.
- `tokens/light.json`, `tokens/dark.json`: the same 19 semantic names, each an alias to a core token, e.g. `"{core.blue.53}"`.
- `src/styles/tokens.css`: GENERATED by `sd.config.mjs` (Style Dictionary). Light in `@theme static`, dark in `.dark`. Never edit it by hand.

### Semantic names (Tailwind: `bg-*`, `text-*`, `border-*`, `ring-*`)

| Token | Use |
|---|---|
| `background` / `foreground` | page surface and its text |
| `card` / `card-foreground` | raised surface and its text |
| `popover` / `popover-foreground` | menus, popovers |
| `primary` / `primary-foreground` | main action, links |
| `secondary` / `secondary-foreground` | secondary action |
| `muted` / `muted-foreground` | quiet surface, helper text |
| `accent` / `accent-foreground` | hover and highlight |
| `destructive` / `destructive-foreground` | delete, errors |
| `border` | dividers, card edges |
| `input` | form control borders (needs 3:1) |
| `ring` | focus ring (needs 3:1) |

### Rules

- Components use semantic names only (`bg-primary`). Never core tokens, raw `hsl()` or hex.
- Change a color in `tokens/*.json`, then run `npm run tokens:build`. Commit the JSON and `tokens.css` together.
- Every name must exist in both `light.json` and `dark.json`.
- A new `*-foreground` token needs a pair added in `scripts/contrast.mjs`.
- Contrast: text 4.5:1, UI boundaries 3:1. `npm run tokens:check` enforces this and runs in CI (`.github/workflows/tokens.yml`).
- Keep values as `hsl(H S% L%)`. The contrast script parses only that format.
